## Apêndice A · Painel laboratorial mínimo da fadiga

Painel a ser pedido em qualquer adulto com fadiga inexplicada após auditoria primária inicial.

| Marcador | Faixa Plenya · alvo |
|---|---|
| Hemograma com VCM, HCM, RDW | Sem anemia · VCM 88-94 · RDW < 13,5 |
| Ferritina | > 70 (mulher c/ queixa) · > 80 (homem) · > 75-100 (RLS) |
| Saturação de transferrina | 25-45% (< 20% deficiência funcional · > 45% investigar hemocromatose) |
| B12 sérica + MMA + homocisteína | B12 > 600 · MMA < 0,4 · Hcy < 8 |
| TSH + T4 livre + T3 livre + anti-TPO | TSH 1,0-2,0 · T4L terço médio-superior · T3L > 3,0 · anti-TPO < 35 |
| Vitamina D 25-OH | 40-60 ng/mL (em paciente c/ queixa) |
| Magnésio eritrocitário | > 5,2 mEq/L (sérico não serve) |
| Glicemia jejum + insulina + HOMA-IR + HbA1c | Glic 70-90 · Ins < 8 · HOMA < 2,0 · HbA1c < 5,4% |
| Painel hepático (ALT, AST, GGT, FA, bilirrubinas, albumina, INR) | Normais |
| Função renal · creatinina + eGFR + RAC urinária | eGFR > 60 · RAC < 30 mg/g |
| Cálcio iônico + PTH | Em paciente > 50 anos ou com sintomas sugestivos |
| PCR-us | < 1,0 mg/L |
| Cortisol salivar 4 pontos | Em estresse crônico ou apresentação atípica |
| PHQ-9 + GAD-7 | < 5 cada |

## Apêndice B · Timeline esperado por intervenção

Tempo até efeito clínico mensurável após início da intervenção. **Calibrar expectativa do paciente é parte do tratamento.**

| Intervenção | Tempo até efeito clínico | O que esperar |
|---|---|---|
| **CPAP em apneia** | 1-4 semanas | Sono restaurador · energia subjetiva |
| **Reposição de ferro oral** | Hb: 4-8 sem · Ferritina-alvo (>70): 12-24 sem | Energia melhora antes de ferritina-alvo |
| **Ferro IV (DRC, má-absorção)** | 2-6 semanas | Mais rápido que oral |
| **B12 metilcobalamina sublingual** | MMA/Hcy: 4-12 sem · neurológicos: 6-12 meses (parcialmente irreversíveis) | Cognitivos demoram mais |
| **Vitamina D 4.000 UI/d** | 25-OH-D em alvo: 8-12 sem · sintomas: meses | Resposta anímica/cognitiva modesta |
| **Magnésio glicinato** | Mg eritrocitário-alvo: 4-8 sem · sono e cãibras: 1-4 sem | Resposta rápida sintomas musculares |
| **CoQ10 ubiquinol em estatina** | Sérico-alvo: 4-8 sem · mialgia: 4-12 sem · fadiga: 8-16 sem | Variável conforme depleção |
| **Levotiroxina (hipotireoidismo)** | TSH normalizar: 6-8 sem · sintomas: 4-12 sem | Não esperar resposta no 1º mês |
| **SGLT2 em HFpEF** | Sintomas: 4-12 sem · NT-proBNP: 6-12 sem | Mortalidade é cumulativa |
| **Antidepressivo (ISRS/IRSN)** | Resposta: 4-8 sem · remissão: 8-16 sem | Efeitos colaterais primeiras 2-4 sem |
| **TCC para depressão/ansiedade/insônia** | 8-16 sessões | Mais sustentável que farmacológico em leves-moderados |
| **Ashwagandha KSM-66** | 4-12 sem | Magnitude modesta (15-25%) |
| **Niacinamida 500 mg/d teste curto** | 8 sem | Magnitude 15-25% · suspender se sem efeito |
| **NMN/NR (peça de afinação)** | Teste 12 sem | Expectativa modesta · não primeira linha |
| **Atividade física estruturada** | Sintomas: 4-12 sem · marcadores: 12-24 sem · VO₂máx: 12-24 sem | Maior intervenção isolada para fadiga |
| **Dieta mediterrânea + redução de ultraprocessado** | Sintomas: 4-12 sem · marcadores: 8-24 sem | Especialmente em inflamação subclínica |
| **Sono adequado (7-8h consistente)** | 1-4 semanas | Frequentemente a maior intervenção possível |
| **Reposição de ferro com ferritina-alvo em RLS** | 8-12 semanas | Alvo > 75-100 |
| **Selenometionina em Hashimoto** | Anti-TPO: 6-12 meses | Adjuvante |
| **Cessação tabágica em DPOC** | Tosse e dispneia: 4-12 sem · função pulmonar: meses-anos | Reduz declínio para o normal |
| **Hidroxicloroquina em LES/Sjögren** | 6-12 semanas | Modificadora de doença |

## Apêndice C · Os doze antagonismos críticos · o que sabota absorção

Interações que **destroem absorção** de suplemento ou geram efeito adverso. Memorizar é mais importante que decorar a forma química.

| Antagonismo | Conduta |
|---|---|
| **Cálcio + Ferro** | Separar por **2 horas mínimo**. Lácteos, suplemento Ca, antiácidos cálcicos não junto com ferro. |
| **Café/chá + Ferro** | Separar por **2 horas mínimo**. Taninos quelam ferro, queda de absorção até 90%. |
| **IBP (omeprazol) + Ferro** | Em uso crônico, **preferir bisglicinato**. Avaliar suspensão de IBP se possível. |
| **Cálcio + Magnésio em alta dose** | Competição parcial. Em altas doses, **separar por 2 horas**. |
| **Zinco isolado em alta dose > 6 meses** | **Adicionar cobre 1-2 mg/d** ou monitorar razão Zn/Cu. |
| **5-HTP + ISRS/IRSN/IMAO** | **Contraindicação absoluta** · síndrome serotoninérgica. |
| **L-tirosina + IMAO** | **Contraindicação** · crise hipertensiva. |
| **L-tirosina + hipertireoidismo** | **Contraindicação** · pode aumentar T4. |
| **Rhodiola + bipolar não tratado** | **Cuidado** · risco de hipomania. |
| **Reishi + anticoagulante** | Cuidado com efeito antiagregante leve aditivo. |
| **NAC + asma** | Raro broncoespasmo paradoxal · suspender se ocorrer. |
| **Ashwagandha + hipertireoidismo** | **Contraindicação relativa** · pode aumentar T4. |

## Apêndice D · As doze sinergias preferidas · o que multiplica o efeito clínico

Combinações que **multiplicam o efeito** quando tomadas juntas no horário certo.

| Sinergia | Como usar |
|---|---|
| **Ferro + vitamina C** | 100 mg vit C com ferro = absorção dupla. |
| **Vitamina D + K2 MK-7** | 4.000 UI D + 90-180 µg K2 com refeição gordurosa. |
| **Magnésio glicinato + glicina noturna** | 300 mg Mg + 3 g glicina antes de dormir = sono profundo. |
| **CoQ10 + estatina** | Ubiquinol 100-200 mg/d com refeição gordurosa enquanto estatina em uso. |
| **B12 + folato 5-MTHF + B6 P5P** | Trio de metilação · homocisteína < 8. |
| **B2 + magnésio + CoQ10 + matricária** | Combinação Plenya em prevenção de enxaqueca. |
| **L-tirosina + L-teanina + cafeína** | Pré-trabalho cognitivo intenso · stack de foco moderado. |
| **Selênio + zinco + iodo (em alvo)** | Conversão T4→T3 + função tireoidiana otimizada. |
| **Creatina + treino de força** | Pós-treino com proteína + carboidrato moderado. |
| **Cordyceps + Rhodiola pela manhã** | Energizante adaptogênico + ergogênico leve. |
| **Ashwagandha + magnésio glicinato à noite** | Cortisol modulado + sono profundo. |
| **Ômega-3 EPA + vitamina D + magnésio** | Trio anti-inflamatório de manutenção. |
