# Descrição KDP (Amazon)

Texto oficial para o campo "Book Description" do KDP. Aceita HTML básico: `<b>`, `<i>`, `<br>`, `<h4>`, `<ul>`, `<li>`, `<p>`. Limite 4.000 caracteres.

Base: contracapa.md (hook Ricardo) + blocos adicionais otimizados para conversão Amazon (O que você encontra / Para quem é / Sobre o autor / fechamento-mantra).

## Observações de SEO/conversão

- **Primeiros ~200 caracteres** aparecem no preview de busca do Amazon antes do "Leia mais" — o hook Ricardo está todo aí, em bold, para segurar o clique.
- **Palavras-chave embutidas naturalmente:** medicina preventiva, biomarcadores, check-up, longevidade, método AGIR, nefrologista.
- **Sem emojis e sem CAPSLOCK** — KDP rejeita descrições com abuso disso.
- **Listas curtas (5 bullets máx)** — algoritmo privilegia densidade de informação sem parede de texto.
- **Fechamento-mantra em itálico** ecoa o subtítulo da capa ("— onde a saúde é decidida") e o lema Plenya ("Viva Bem, Viva Mais").
