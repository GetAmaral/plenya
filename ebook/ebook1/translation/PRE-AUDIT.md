# BEFORE — Pre-Audit (PT → EN)

Auditoria capítulo a capítulo dos itens BR-específicos que **precisarão de adaptação** na tradução. Este documento é o complemento operacional do `STYLE-EN.md` e do `GLOSSARY.md`.

Versão: 1.0 · Data: 2026-05-01.

---

## Como usar este documento

Antes de traduzir um capítulo:

1. Leia a seção do capítulo correspondente abaixo.
2. Para cada item, verifique a estratégia indicada (manter / adaptar / complementar).
3. Aplique no rascunho.
4. Marque `[?]` se a estratégia gerar dúvida concreta.

**Categorias** (consistentes em todos os capítulos):
- 🔴 **REGULATÓRIO** — Anvisa, CFM, CRM, RDC, SUS, ANS, RQE
- 🟡 **CULTURAL** — alimentos, lugares, expressões, contextos brasileiros
- 🔵 **CLÍNICO BR** — práticas, programas, disponibilidade de medicamentos no Brasil
- 🟢 **ESTATÍSTICA** — dados IBGE, DATASUS, Ministério da Saúde
- 🟣 **ESTUDOS BR** — coortes, pesquisadores, sociedades científicas brasileiras
