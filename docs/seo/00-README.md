## Princípios

- **NAP idêntico em TODO lugar** — qualquer divergência (`Av.` vs `Avenida`, ou telefone diferente) confunde o Google e quebra Local Pack.
- **CFM 2.336/2023** — proibido "o melhor", "garantia", "cura", antes/depois sensacionalista. Já auditamos os sites; aplique a mesma regra nos perfis externos.
- **Não comprar reviews** — proibido por CFM e detectado pelo Google.
- **Conteúdo do Plenya é o ímã, não os perfis** — listings dirigem visita pro site canônico, onde temos schema, autor, revisão clínica.
