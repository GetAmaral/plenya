## Ordem sugerida de leitura

**Para o palestrante (preparação para ensaio):**
1. Ler [oratoria-referencias.md](./oratoria-referencias.md) — absorve a voz-guia e as técnicas.
2. Ler [roteiro.md](./roteiro.md) — memorizar abertura, confissão, Bloco R e fechamento palavra-por-palavra. O resto, em tópicos.
3. Consultar [citacoes-livro.md](./citacoes-livro.md) para lembrar frases exatas do livro a reusar no palco.

**Para o designer (produção dos slides):**
1. Ler [slides-outline.md](./slides-outline.md) — 72 slides com especificação completa.
2. Consultar brand system Plenya (pasta do site).
3. Reaproveitar figuras do livro em `/home/user/plenya/ebook/Ebook 1 - Performance e Longevidade/*.PNG`.

**Para divulgação comercial:**
1. [onepager.md](./onepager.md) — exportar para PDF e enviar para 20 contatos estratégicos.
2. Após primeira palestra: substituir seção "Prova social" com testemunhos e logos.

## Fundação do material

- **Livro ANTES** lido integralmente (18 capítulos + bíblia de personagens + agradecimentos + contracapa + sobre o autor).
- **Pesquisa de oratória** de 17 palestrantes mundiais (ver `oratoria-referencias.md`).
- **Análise de ROI** das 4 ideias comerciais do autor (livro + palestra + autoridade + Plenya) — a palestra emergiu como o vetor de maior retorno financeiro e estratégico.
