## Q&A opcional (10–15 min)

### Regras de palco para Q&A

- **Ficar em pé** (não sentar).
- **Repetir a pergunta** antes de responder (70% da plateia não ouviu).
- **Respostas curtas** (2–3 min máximo). Se a pergunta for complexa, ancorar em um dos 6 pacientes.
- **Não anunciar o livro.** Se perguntarem "onde comprar", responder com naturalidade. Nunca trazer à tona.
- **Encerramento de Q&A:** uma última pergunta, resposta curta, "obrigado a todos" e sair. Zero PowerPoint de encerramento adicional.

### Perguntas antecipáveis

1. *"Meu médico nunca pediu esses exames. Devo procurar outro?"*
   → "Não necessariamente. Às vezes, levar esta lista pra ele abre uma conversa que nunca aconteceu. Se ele resistir, a resistência é a resposta — mas dê a chance primeiro."

2. *"Quanto custa fazer esse painel ampliado no Brasil?"*
   → Faixa real, sem maquiar: R$ 800–2.500 dependendo de incluir CAC. Plano de saúde cobre alguns itens, outros não. Custo anual equivale a uma mensalidade de academia boa.

3. *"E a genética? Se meu pai teve infarto jovem, estou condenado?"*
   → Genética é contexto, não destino. APOE4 — o pior gene para Alzheimer — se beneficia MAIS das intervenções de estilo de vida, não menos (estudos FINGER, MAPT).

4. *"Suplementos: quais valem a pena?"*
   → Quatro com evidência mais forte: vitamina D + K2, magnésio glicinato, ômega-3 EPA+DHA, creatina. Tudo ajustado por painel.

5. *"Testosterona — reposição faz sentido?"*
   → Paulo restaurou sem hormônio. Primeira linha é sempre isso. Reposição é para quem não responde a sono + vitamina D + treino. Nunca é a primeira prescrição.

6. *"E se eu já tenho diagnóstico — diabetes, HAS?"*
   → O livro foi escrito para ANTES. Mas tudo que tem no livro se aplica DEPOIS também — só que o custo de reverter é maior e algumas trajetórias são irreversíveis. Começar hoje continua sendo melhor que começar amanhã.
